# 妙子家的皮涂 · 小红书风格狗狗日常主页

单文件网页（**index.html**，双击即用、零依赖），展示小红书账号「妙子家的皮涂」的日常主页名片：

- 真实头像、真实简介（田园犬涂涂 + 比熊妹妹四月）
- 14 条真实笔记：封面、标题、点赞数均来自账号公开发布内容
- 真实小红书主页二维码与主页链接
- 话题筛选（全部 / 我的日常 / 遛弯 / 拆家现场）、点赞/收藏微动效、＋关注交互、浏览器原生分享

## 技术说明

- 单个 HTML 文件：CSS / JS / 图片全部内嵌（base64），无需任何服务与网络
- 数据集中在 JS 顶部的 `ACCOUNT` 与 `NOTES` 对象，改昵称、简介、笔记、数字都改那里
- 粉丝数、评论/收藏数字为占位（小红书未登录页不开放显示）

## 使用

双击 `index.html` 即可浏览；想发布到任意静态托管（GitHub Pages / Netlify 等），直接上传这一个文件即可。
